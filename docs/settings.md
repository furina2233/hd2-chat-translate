# 游戏内设置

本插件通过单独安装的 [Mod Options Menu v1.2](https://github.com/CowboyBingus/ModOptionsMenu/releases/tag/v1.2)，在游戏 ESC 菜单的原生 `MODS` 页注册目标语言、启用、不翻译自己说的话、将敌人翻译为口语、请求超时和接口类型六项。

菜单标题、说明、目标语言名称和超时单位会跟随游戏的 Text Language。支持英语、英式英语、法语、意大利语、德语、西班牙语、拉丁美洲西班牙语、日语、韩语、巴西葡萄牙语、葡萄牙语、波兰语、俄语、简体中文和繁体中文。切换游戏语言后关闭并重新打开 ESC 菜单即可刷新；不支持的地区变体会尝试对应的基础语言，仍未匹配时显示英语。

## 选择目标语言

1. 打开 ESC → MODS → HD2 Chat Translate。
2. 选择目标语言，默认简体中文。
3. 设置“启用”和“不翻译自己说的话”，两项默认开启；设置“将敌人翻译为口语”，默认开启；设置“请求超时”，默认20秒。
4. 选择“接口类型”，菜单默认免费版。
5. 按 APPLY 应用修改；键盘默认使用 Tab。未应用的选择不会改变翻译设置。

可选简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语和意大利语。选择会保存，并在下次启动时恢复。

目标语言、启用状态、自己消息过滤、敌人俗称、超时和接口类型均在任务开始处理时读取一次。APPLY 后开始处理的任务使用新设置；已开始的任务保留自己的设置快照。已有聊天不会重新翻译。任何服务返回的译文与原文完全相同时都保留原文。

关闭“启用”后，插件仍会监听聊天框，但后续任务保留原文且不发送网络请求。想完全移除插件，请在模组管理器中卸载。超时可选10、20或30秒；单个任务从提交开始最多保留60秒。

开启“不翻译自己说的话”后，插件会跳过识别为你发送的消息。它会尝试记录启动时单人发送者列表中的玩家姓名和颜色；当前发送者列表中姓名唯一时按姓名识别。出现同名时，先确认当前自己的颜色仍与启动时记录的颜色相同，再比较消息颜色。若同名情况下自己的颜色已改变，或所需身份信息无法确认，消息都会照常翻译。该设置不会重新处理已有聊天。

默认中文目标下，AI 翻译保留中文消息；选择英语等其他目标语言后，中文消息也可以被翻译。

“将敌人翻译为口语”仅在使用 Chat Completions 或 Anthropic AI 接口且目标语言为简体中文时生效，默认开启。启用后，AI 会按口语表达翻译游戏内敌人名字，并增加 token 消耗；关闭后仍使用中文网络缩写和 `reinforce`、`extract` 等游戏术语规则。繁体中文及其他目标语言不追加中文提示；免费版和机器翻译不受此设置影响。

菜单只负责显示和保存选择，原生客户端按已应用的接口类型读取服务配置。缓存按原文、目标语言及服务配置区分；AI 缓存还包含实际系统提示，因此简体中文目标下切换敌人俗称设置会分别缓存结果，其他目标下相同的提示仍可复用缓存。

## 选择接口类型

可选项依次为“免费版”“Chat Completions接口”“Anthropic接口”“百度翻译”“有道翻译”“必应翻译国内版”“必应翻译国际版”“谷歌翻译”。提供商由菜单选择确定；机器翻译使用内置的官方接口地址，不读取 `HD2CT_API_URL` 和 `HD2CT_MODEL`。

| 接口类型 | Windows 持久环境变量 |
| --- | --- |
| 免费版 | 无需提供商配置，使用 Bing 网页翻译 |
| Chat Completions接口 | `HD2CT_API_URL`、`HD2CT_MODEL`、`HD2CT_API_KEY` |
| Anthropic接口 | `HD2CT_API_URL`、`HD2CT_MODEL`、`HD2CT_API_KEY` |
| 百度翻译、有道翻译 | `HD2CT_APP_ID`、`HD2CT_API_KEY` |
| 必应翻译国内版、国际版 | `HD2CT_API_KEY`；可选 `HD2CT_REGION` |
| 谷歌翻译 | `HD2CT_API_KEY` |

各机器翻译接口使用固定地址，不能通过环境变量覆盖：

| 提供商 | 接口地址 |
| --- | --- |
| 百度翻译 | `https://fanyi-api.baidu.com/api/trans/vip/translate` |
| 有道翻译 | `https://openapi.youdao.com/api` |
| 必应翻译国内版 | `https://api.translator.azure.cn/translate` |
| 必应翻译国际版 | `https://api.cognitive.microsofttranslator.com/translate` |
| 谷歌翻译 | `https://translation.googleapis.com/language/translate/v2` |

必应国内版对应 Azure 中国区官方 API，国际版对应全球 Azure。区域或多服务资源需要填写资源地区 `HD2CT_REGION`，密钥应与所用 Azure 云、资源及地区匹配。

AI 接口使用 `HD2CT_API_URL` 自定义地址。Anthropic 地址可填根地址、以完整路径段 `/v1` 结尾的地址（兼容 `/v1/`，会去掉尾斜杠后追加 `/messages`）或完整 `/v1/messages` 地址；代理等其他自定义路径需填写完整端点。Chat Completions 的地址补全规则及其他协议详见[技术说明](technical.md#配置与-httpjson-协议)。服务配置在后台开始处理每条消息时读取，修改持久环境变量后不必重启游戏；已经开始的请求保留原配置。

## 保存位置与默认值

Mod Options Menu 将已应用的选择保存到 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ModOptionsMenu.values`，并维护 `.bak` 备份。该文件由菜单框架管理，本插件只读取自己的六项设置，不改写其他模组的选项。读取发生在原生后台 worker 取到任务后；游戏线程上的提交和轮询不访问该文件。

本插件的语言项缺失、越界或无效时使用简体中文；启用项、“不翻译自己说的话”和“将敌人翻译为口语”缺失或无效时默认开启；超时项缺失或无效时默认20秒；接口类型尚未保存、缺失或无效时使用免费版。不要为重置一项设置删除整个共享文件，以免重置其他模组的选项；在菜单中分别选择默认值并应用即可。

菜单框架及本插件都受已支持游戏构建的门禁限制。游戏更新后，菜单未出现或翻译未生效时，先确认模组部署、加载优先级及游戏版本。

本安装包不包含前置模组，使用前需单独安装 Bingus Shared Loader v18 和兼容 v1.2 接口的 Mod Options Menu。若其他模组已提供菜单，框架会复用先加载的实例；避免同时部署不同版本。
