# 游戏内设置

安装包合并 [Mod Options Menu v1.2](https://github.com/CowboyBingus/ModOptionsMenu/releases/tag/v1.2)，在游戏 ESC 菜单中提供原生 `MODS` 页。本插件注册收到消息的目标语言、启用和请求超时设置，以及发送前翻译开关和发送目标语言。

菜单标题、说明、目标语言名称和超时单位会跟随游戏的 Text Language。支持英语、英式英语、法语、意大利语、德语、西班牙语、拉丁美洲西班牙语、日语、韩语、巴西葡萄牙语、葡萄牙语、波兰语、俄语、简体中文和繁体中文。切换游戏语言后关闭并重新打开 ESC 菜单即可刷新；不支持的地区变体会尝试对应的基础语言，仍未匹配时显示英语。

## 选择目标语言

1. 打开 ESC → MODS → HD2 Chat Translate。
2. 选择目标语言，默认简体中文。
3. 设置“启用”，默认开启；设置“请求超时”，默认20秒。
4. 按 APPLY 应用修改；键盘默认使用 Tab。未应用的选择不会改变翻译设置。

可选简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语和意大利语。选择会保存，并在下次启动时恢复。

收到消息的目标语言、启用状态和超时在入站任务开始处理时读取一次。APPLY 后开始处理的任务使用新设置；已开始的任务保留自己的设置快照。已有聊天不会重新翻译。任何服务返回的译文与原文完全相同时都保留原文。

## 发送消息前翻译

“翻译我的消息再发送”默认关闭；“将我的话翻译为”默认英语。启用后，自己发送的消息会先进入有界队列，按此处的独立目标语言翻译，再由游戏原发送路径发送。收到消息的显示仍使用上方“目标语言”设置。

翻译失败、超时、译文无效或超过游戏发送长度时，队列会按原顺序发送原文，不会把错误提示当作聊天内容发送。关闭主“启用”或“翻译我的消息再发送”后，已排队消息会按原文依次发送；新的消息直接按原文发送。队伍、接收者或游戏会话变化时，未发送的旧队列会取消，避免发给新的接收者。

原生后台 controller 每秒读取一次已应用的设置。出站消息入队时会快照发送目标语言和超时；controller 发现发送开关关闭后停止接收新消息，已有队列仍保留原顺序并在安全的游戏线程机会到来时回退原文。游戏线程不读取设置文件；若更新泵暂时失鲜，待发送原文会留在有界队列中，直到下一次安全泵或聊天发送机会。

关闭主“启用”后，插件仍会监听收到的聊天，但后续入站任务保留原文且不发送网络请求；自己的新消息则直接按原文发送。想完全移除插件，请在模组管理器中卸载。超时可选10、20或30秒；单个任务从提交开始最多保留60秒。

默认中文目标下，AI 翻译保留中文消息；选择英语等其他目标语言后，中文消息也可以被翻译。

AI 仅在简体中文目标下使用中文网络缩写和游戏术语规则；繁体中文目标使用通用目标语言提示。

菜单只负责显示和保存选择，服务地址、密钥和适配器选择仍由原生客户端管理。缓存按原文和目标语言区分，切换语言不会复用其他目标语言的译文。

## 保存位置与默认值

Mod Options Menu 将已应用的选择保存到 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ModOptionsMenu.values`，并维护 `.bak` 备份。该文件由菜单框架管理，本插件只读取自己的收到消息目标语言、主启用、请求超时、发送前翻译开关和发送目标语言，不改写其他模组的选项。入站 worker 在开始处理任务时读取入站设置；原生后台 controller 每秒读取主启用、超时、发送开关和发送目标，出站任务在拦截时快照发送目标与超时。游戏线程上的提交和轮询不访问该文件。

本插件的收到消息语言项缺失、越界或无效时使用简体中文；主启用项缺失或无效时默认开启；超时项缺失或无效时默认20秒。发送前翻译项缺失或无效时默认关闭；发送目标缺失、越界或无效时默认英语。不要为重置一项设置删除整个共享文件，以免重置其他模组的选项；在菜单中分别选择默认值并应用即可。

菜单框架及本插件都受已支持游戏构建的门禁限制。游戏更新后，菜单未出现或翻译未生效时，先确认模组部署、加载优先级及游戏版本。

如果其他模组已经提供 Mod Options Menu，框架会复用先加载的实例。应保留兼容 v1.2 接口的版本，避免同时部署不同版本；本安装包已包含菜单，无需另行安装。
