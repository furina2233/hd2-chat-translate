# 游戏内设置

安装包合并 [Mod Options Menu v1.2](https://github.com/CowboyBingus/ModOptionsMenu/releases/tag/v1.2)，在游戏 ESC 菜单中提供原生 `MODS` 页。本插件注册目标语言、启用和请求超时三项。

菜单标题、说明、目标语言名称和超时单位会跟随游戏的 Text Language。支持英语、英式英语、法语、意大利语、德语、西班牙语、拉丁美洲西班牙语、日语、韩语、巴西葡萄牙语、葡萄牙语、波兰语、俄语、简体中文和繁体中文。切换游戏语言后关闭并重新打开 ESC 菜单即可刷新；不支持的地区变体会尝试对应的基础语言，仍未匹配时显示英语。

## 选择目标语言

1. 打开 ESC → MODS → HD2 Chat Translate。
2. 选择目标语言，默认简体中文。
3. 设置“启用”，默认开启；设置“请求超时”，默认20秒。
4. 按 APPLY 应用修改；键盘默认使用 Tab。未应用的选择不会改变翻译设置。

可选简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语和意大利语。选择会保存，并在下次启动时恢复。

目标语言、启用状态和超时均在任务开始处理时读取一次。APPLY 后开始处理的任务使用新设置；已开始的任务保留自己的设置快照。已有聊天不会重新翻译。任何服务返回的译文与原文完全相同时都保留原文。

关闭“启用”后，插件仍会监听聊天框，但后续任务保留原文且不发送网络请求。想完全移除插件，请在模组管理器中卸载。超时可选10、20或30秒；单个任务从提交开始最多保留60秒。

默认中文目标下，AI 翻译保留中文消息；选择英语等其他目标语言后，中文消息也可以被翻译。

AI 仅在简体中文目标下使用中文网络缩写和游戏术语规则；繁体中文目标使用通用目标语言提示。

菜单只负责显示和保存选择，服务地址、密钥和适配器选择仍由原生客户端管理。缓存按原文和目标语言区分，切换语言不会复用其他目标语言的译文。

## 保存位置与默认值

Mod Options Menu 将已应用的选择保存到 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ModOptionsMenu.values`，并维护 `.bak` 备份。该文件由菜单框架管理，本插件只读取自己的目标语言、启用和超时项，不改写其他模组的选项。读取发生在原生后台 worker 取到任务后；游戏线程上的提交和轮询不访问该文件。

本插件的语言项缺失、越界或无效时使用简体中文；启用项缺失或无效时默认开启；超时项缺失或无效时默认20秒。不要为重置一项设置删除整个共享文件，以免重置其他模组的选项；在菜单中分别选择默认值并应用即可。

菜单框架及本插件都受已支持游戏构建的门禁限制。游戏更新后，菜单未出现或翻译未生效时，先确认模组部署、加载优先级及游戏版本。

如果其他模组已经提供 Mod Options Menu，框架会复用先加载的实例。应保留兼容 v1.2 接口的版本，避免同时部署不同版本；本安装包已包含菜单，无需另行安装。
