# 游戏内设置

安装包合并 [Mod Options Menu v1.2](https://github.com/CowboyBingus/ModOptionsMenu/releases/tag/v1.2)，在游戏 ESC 菜单中提供原生 `MODS` 页。本插件只注册“目标语言”一项，默认简体中文。

## 选择目标语言

1. 打开 ESC → MODS → HD2 Chat Translate。
2. 在“目标语言”行选择语言。
3. 按 APPLY 应用修改；键盘默认使用 Tab。未应用的选择不会改变翻译目标。

可选简体中文、繁体中文、英语、日语、韩语、法语、德语、西班牙语、葡萄牙语、意大利语、俄语、阿拉伯语、泰语和越南语。选择会保存，并在下次启动时恢复。

修改后，后续开始处理的翻译任务使用新目标语言；正在处理的任务保留自己的语言快照。已有聊天不会重新翻译。任何服务返回的译文与原文完全相同时都保留原文。

默认中文目标下，AI 翻译保留中文消息；选择英语等其他目标语言后，中文消息也可以被翻译。

菜单只负责显示和保存选择，服务地址、密钥、适配器选择及启用状态仍由原生客户端管理。缓存按原文和目标语言区分，切换语言不会复用其他目标语言的译文。

## 保存位置与默认值

Mod Options Menu 将已应用的选择保存到 `%LOCALAPPDATA%\CowboyBingus\Helldivers2\Logs\ModOptionsMenu.values`，并维护 `.bak` 备份。该文件由菜单框架管理，本插件只读取自己的目标语言项，不改写其他模组的选项。

本插件的语言项缺失、越界或无效时使用简体中文。不要为重置一项设置删除整个共享文件，以免重置其他模组的选项；在菜单中选择简体中文并应用即可。

菜单框架及本插件都受已支持游戏构建的门禁限制。游戏更新后，菜单未出现或翻译未生效时，先确认模组部署、加载优先级及游戏版本。

如果其他模组已经提供 Mod Options Menu，框架会复用先加载的实例。应保留兼容 v1.2 接口的版本，避免同时部署不同版本；本安装包已包含菜单，无需另行安装。
