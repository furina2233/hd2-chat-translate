# HD2 Chat Translate

《绝地潜兵 2》聊天框翻译插件。支持 AI 翻译和机器翻译，支持翻译为多种语言。译文不会被发送给其他玩家。

当前兼容范围为 Steam build 25480438、游戏 EXE 1.8.46015.0。游戏更新可能导致本插件失效。

> **使用风险：** 插件会注入游戏进程、执行代码并调用游戏内部函数更新聊天显示。此行为可能违反游戏或反作弊规则，并导致账号处罚或封禁。

英文版说明：[README_EN.md](docs/README_EN.md)

## 安装与更新

1. 正常关闭游戏，在 HD2Arsenal 导入。
2. 点击部署。需要你已安装`Bingus Shared Loader`和`Mod Options Menu`两个前置模组。
3. 启动游戏。

## 免费使用、开箱即用

安装本插件后即使不配置任何环境变量，也能直接免费使用。

免费版本由Bing翻译提供服务，不保证持续可用。

## 配置

支持的翻译提供商：
- 免费翻译：开箱即用，不需要进行任何配置，此时不需要了解下方的配置方式介绍
- AI翻译：所有提供Chat Completions或Anthropic接口且支持JSON mode的提供商
- 机器翻译：Google、百度、有道、必应国内版、必应国际版

在 Windows 环境变量设置中填写以下配置：

| 变量 | 内容 | 必填 |
| --- | --- | --- |
| HD2CT_API_URL | 所选AI提供商的接口地址 | AI翻译必填 |
| HD2CT_MODEL | AI 模型名 | AI翻译必填 |
| HD2CT_API_KEY | AI/Google 的 API Key，或百度/有道的应用密钥 | 是 |
| HD2CT_APP_ID | 百度 APP ID 或有道应用 ID | 百度/有道必填 |

注意：
- 翻译时，若源语言和目标语言相同，则不会显示译文行，这不是bug。
- 修改环境变量后需要重启游戏才能生效。

设置页中可以进行其他调整：

| 设置项 | 内容 |
| --- | --- |
| 目标语言 | 译文的语言 |
| 启用 | 是否启用翻译 |
| 不翻译自己说的话 | 启用后将不会翻译自己发送的消息 |
| 超时 | 请求超时时长 |
| 接口类型 | 翻译服务接口的类型 |
| 将敌人翻译为口语 | 仅AI翻译且目标语言为中文生效，将敌人名字翻译为口语 |

注意：
- 无论是否启用，插件都会监听聊天框，想要完全移除，请在模组管理器中卸载。
- 设置页中进行的修改会即时生效，不需要重启游戏

## 可见提示与基础排查

常见请求失败会保留原文，并在译文位置显示以下提示：

| 场景 | 可见提示 | 基础排查 |
| --- | --- | --- |
| 所选接口缺少必填配置 | 翻译配置不完整 | 核对游戏内“接口类型”；AI 需要地址、模型名和密钥，机翻需要密钥，百度、有道还需要应用 ID。免费版无需环境变量。 |
| 配置值格式无效 | 翻译配置无效 | 检查配置是否含多余空白、引号或超长内容；必应的 Region 应与资源地区匹配。 |
| AI 接口地址无效 | 接口地址无效 | 使用 HTTPS 地址，不附带密钥、查询参数或片段；机翻地址由插件内置。 |
| HTTP 400、422 或服务拒绝请求参数 | 请求参数有误 | 核对接口类型、模型名及该服务支持的请求格式。 |
| HTTP 401 | API 密钥无效 | 检查所选服务的密钥是否正确、有效。 |
| 机翻凭据或签名校验失败 | 翻译凭据或签名无效 | 核对应用 ID 与密钥是否属于同一应用；必应还需核对云区域及 Region。 |
| HTTP 403 或服务拒绝访问 | 无权使用此接口 / 无权使用此翻译服务 | 确认账号已开通对应接口，密钥具有访问权限。 |
| HTTP 404 | 接口或模型不存在 | AI 模式下检查地址和模型名；机翻或免费版可能是上游接口发生变化。 |
| 请求超时，或 HTTP 408、504 | 请求超时 | 检查网络；可在游戏内提高请求超时，或切换服务。 |
| HTTP 429 或服务限流 | 请求太频繁，请稍后再试 | 等待后再发送，减少短时间内连续请求。 |
| 连续失败后的短暂退避 | 请稍后重试 | 等待片刻；若反复出现，先排查此前的请求错误。 |
| 其他 HTTP 5xx | 服务暂时不可用 | 等待上游恢复，或在“接口类型”中切换服务。 |
| 网络连接失败 | 网络连接失败 | 检查所选服务是否可访问，以及网络、代理设置；免费版需要能访问 Bing 网页翻译。 |
| 响应结构无效或内容过长 | 返回内容无效 / 返回内容过长 | AI 服务须返回符合要求的 JSON；检查接口、模型兼容性，或换服务重试。 |
| 翻译账户额度不足 | 翻译额度不足 | 检查当前提供商的余额和额度，或切换服务。 |
| 服务不支持请求的语言 | 不支持此语言 | 在设置中更换目标语言，或选择支持该语言的服务。 |
| 任务未能入队 | 翻译请求未能提交 | 等待正在处理的消息完成后再试。 |
| 其他失败 | 翻译服务异常 / 翻译失败，请稍后重试 | 稍后重试；持续失败时检查本地日志、游戏版本及模组是否正确部署。 |

## 本地日志

日志位于 `%LOCALAPPDATA%\HD2ChatTranslate`：`probe` 保存启动核验报告，`observe` 保存观察报告，`mailbox` 保存翻译状态报告。插件启动时按各类报告的最后修改时间清理较早文件，每类最多保留 10 个，并为本次会话的新报告预留位置。
