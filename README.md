# HD2 Chat Translate

《绝地潜兵 2》聊天框翻译插件。支持 AI 翻译和机器翻译，支持翻译为多种语言。译文不会被发送给其他玩家。

当前兼容范围为 Steam build 25480438、游戏 EXE 1.8.46015.0。游戏更新可能导致本插件失效。

> **使用风险：** 插件会注入游戏进程、执行代码并调用游戏内部函数更新聊天显示。此行为可能违反游戏或反作弊规则，并导致账号处罚或封禁。

英文版说明：[README_EN.md](docs/README_EN.md)

## 安装与更新

1. 正常关闭游戏，在 HD2Arsenal 导入。
2. 点击部署后启动游戏。需要你已安装`Bingus Shared Loader`和`Mod Options Menu`两个前置模组。

## 免费使用、开箱即用

安装本插件后即使不配置任何环境变量，也能直接免费使用。

免费版本由Bing翻译提供服务，不保证持续可用。

## 配置

支持的翻译提供商：
- 免费翻译：开箱即用，不需要进行任何配置，此时不需要了解下方的配置方式介绍
- AI翻译：所有提供Chat Completions或Anthropic接口且支持JSON mode的提供商
- 机器翻译：Google、百度、有道、必应国内版、必应国际版

在 Windows 环境变量设置中填写以下配置：

| 变量 | 内容 | 必填 |
| --- | --- | --- |
| HD2CT_API_URL | 所选AI提供商的接口地址 | AI翻译必填 |
| HD2CT_MODEL | AI 模型名 | AI翻译必填 |
| HD2CT_API_KEY | AI/Google 的 API Key，或百度/有道的应用密钥 | 是 |
| HD2CT_APP_ID | 百度 APP ID 或有道应用 ID | 百度/有道必填 |

注意：
- 翻译时，若源语言和目标语言相同，则不会显示译文行，这不是bug。
- 修改环境变量后需要重启游戏才能生效。

设置页中可以进行其他调整：

| 设置项 | 内容 |
| --- | --- |
| 目标语言 | 译文的语言 |
| 启用 | 是否启用翻译 |
| 不翻译自己说的话 | 启用后将不会翻译自己发送的消息 |
| 超时 | 请求超时时长 |
| 接口类型 | 翻译服务接口的类型 |

注意：
- 无论是否启用，插件都会监听聊天框，想要完全移除，请在模组管理器中卸载。
- 设置页中进行的修改会即时生效，不需要重启游戏

## 可见提示与基础排查

常见请求失败会保留原文，并在译文位置显示以下提示：

| 情况 | 显示提示 |
| --- | --- |
| HTTP 400 或 422 | 请求参数有误 |
| HTTP 401 | API 密钥无效 |
| HTTP 403 | 无权使用此接口 |
| HTTP 404 | 接口或模型不存在 |
| 超时 | 请求超时 |
| HTTP 429 | 请求太频繁，请稍后再试 |
| 其他 HTTP 5xx | 服务暂时不可用 |
| 网络连接失败 | 网络连接失败 |
| 无效或过长的返回内容 | 返回内容无效或返回内容过长 |
| 配置或地址无效 | 模型配置无效或接口地址无效 |
| 机器翻译 URL 无法匹配服务 | 暂不支持此翻译服务 |
| 应用凭据或签名错误 | 翻译凭据或签名无效 |
| 翻译账户额度不足 | 翻译额度不足 |
| 服务不支持源语言 | 不支持此语言 |
| 其他失败 | 翻译服务异常，或翻译失败，请稍后重试 |

## 本地日志

日志位于 `%LOCALAPPDATA%\HD2ChatTranslate`：`probe` 保存启动核验报告，`observe` 保存观察报告，`mailbox` 保存翻译状态报告。插件启动时按各类报告的最后修改时间清理较早文件，每类最多保留 10 个，并为本次会话的新报告预留位置。
